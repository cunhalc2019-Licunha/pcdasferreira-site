# PC das Ferreira — site institucional

Landing page da **PC das Ferreira Empreendimentos & Engenharia** (imobiliária, construtora e engenharia), Moema – São Paulo/SP.

Site estático: `index.html` + pasta `assets/`. Não precisa de build.

## Publicar na Vercel
1. Importe este repositório em vercel.com/new.
2. Framework: **Other**. Build command: vazio. Output directory: raiz (`.`).
3. Deploy.
